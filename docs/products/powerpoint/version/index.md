# PowerPoint 版本与平台

本页是精选学习范围，不是完整发行历史。记录产品名、版本、系统与实际播放设备，再复现具体操作。

## 学习范围

| 环境 | 建议练习 | 需要确认 |
| --- | --- | --- |
| Microsoft 365 桌面版 | 主题、母版、备注与完整播放 | 更新通道、字体、媒体 |
| 永久许可桌面版，如 2024/2021 | 演示结构、版式和图表 | 新功能和模板是否适用 |
| 网页版 | 协作编辑与基础播放 | 与桌面版的制作和媒体功能差异 |
| 移动版 | 阅读、讲解与小范围修改 | 排版和播放的设备限制 |

母版教程的适用版本可查[微软母版指南](https://support.microsoft.com/en-us/PowerPoint/training/customize-a-slide-master)。网页版不提供桌面版的母版编辑能力，具体平台差异见[微软功能对照](https://support.microsoft.com/en-us/powerpoint/compare-powerpoint-features-on-different-platforms)。辅助功能的建议和适用范围可查[微软无障碍指南](https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities)。查询日期：2026-10-05。

## 兼容检查

在接收方的实际软件中检查版式、字体、图表、链接与媒体。演示制作环境和现场播放环境不同的时候，各自保留一份检查记录。其他办公套件见[工具对照](/matrix/)。
