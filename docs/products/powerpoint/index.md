# PowerPoint 总览

PowerPoint 用于在有限时间里向听众说明问题、展示证据并推动决定。好的演示从结论和叙事开始，再选择布局与视觉表现。

## 适合的任务与边界

适合月度汇报、方案提案、培训和会议分享。需要逐条查阅的制度留在文档中，大量可复核明细留在工作簿中，并作为演示附件。

演示页只承载当前需要讲清的一件事。不要把整份 Word 内容按段落搬上屏幕，也不要把动画数量当作表达质量。

## 核心方法

| 要解决的问题 | 对应方法 |
| --- | --- |
| 听众不知道重点 | 标题先写结论，正文提供证据 |
| 各页字体、位置不一致 | 使用主题、母版与版式 |
| 图表复杂、看不清 | 减少系列，写单位，突出关键变化 |
| 演讲超时 | 准备讲稿并按实际时间排练 |

母版用于统一演示设计，具体操作见[微软母版指南](https://support.microsoft.com/en-us/PowerPoint/training/customize-a-slide-master)。

## 版本与学习路线

先确认[版本与平台](/products/powerpoint/version/)。建议依次学习[结构、叙事与讲稿](/products/powerpoint/storytelling)、[母版、图表与可读性](/products/powerpoint/design)，再完成[月度工作汇报](/scenarios/monthly-report)。
