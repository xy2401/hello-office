# 母版、图表与可读性

设计要帮助听众读懂结论。先统一版式，再处理图片与图表，最后检查阅读和播放效果。

## 母版与版式

在桌面 PowerPoint 的母版视图中统一字体、颜色、页脚和占位符。日常创建幻灯片时选择对应版式，避免每页手工拖拽相同元素。操作范围以[微软母版指南](https://support.microsoft.com/en-us/PowerPoint/training/customize-a-slide-master)与实际平台为准。

## 图表表达一个问题

- 趋势优先考虑折线图，分类比较考虑柱形图。
- 标明时间范围、单位和数据来源，保持同类图表的口径一致。
- 删除无关系列，直接标注重要数值，避免依赖复杂图例。
- 截图使用前检查清晰度，并保留可追溯的数据文件。

费用超支用“预算与实际”的比较解释，不把不同单位的数字画在同一个轴上。不要为了显得变化更大而隐藏坐标范围。

## 可读性与无障碍

为各页提供明确标题，图片写替代文本，检查对象阅读顺序。除了颜色，还使用文字或形状标明状态。用 PowerPoint 的辅助功能检查器查找问题；具体建议见[微软无障碍指南](https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities)。

## 交付前检查

以实际播放尺寸查看一遍，确认文字和图表可读。检查字体替换、备注、隐藏页、链接与媒体。导出 PDF 后再确认页面内容；音视频和动画的效果需要在原生播放环境核对。
