# 结构、叙事与讲稿

先写一句话：听众听完后，需要理解什么或批准什么？接下来的每一页都应帮助完成这个目标。

## 一个五页结构

| 页 | 要回答的问题 | 内容 |
| --- | --- | --- |
| 1. 本次要点 | 今天为什么要听 | 主题、对象、范围 |
| 2. 核心结论 | 最重要的发现是什么 | 一句结论、影响 |
| 3. 支持证据 | 为什么相信这个结论 | 数据、事实、来源 |
| 4. 风险与取舍 | 有什么不确定 | 限制、风险、备选方案 |
| 5. 下一步 | 接下来由谁做什么 | 行动、负责人、期限 |

这个结构适合短汇报，可以按任务合并或扩展。它是写作方法，不是 PowerPoint 的固定功能。

## 写出有效标题

“审批进展”只告诉听众领域；“平均审批时间从五天缩短到三天”直接给出发现。结论需要限定样本和时间范围，不能从局部数字推断整体效果。

先在[办公练习台](/playground/)填好结论、证据、风险和行动，再选择适合的图表或文字结构。

## 备注与演讲分工

页面放关键词、图表和核心结论；备注放解释、过渡和可能被问到的细节。按实际时长排练，记录每页用时，给提问留出空间。

## 结束时推动行动

最后一页写具体决定或下一步，而不只写“谢谢”。例如：“请确认下一月的费用上限；财务在周五前更新预算表。”
