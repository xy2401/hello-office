# 办公应用总览

三类应用对应三类核心工作。先选任务，再学习应用内的结构、数据和协作方法。

| 应用 | 核心用途 | 入门章节 | 任务实践 |

| [Word](/products/word/) | 可持续维护的文字文档 | [样式、目录与分页](/products/word/layout) | [会议纪要](/scenarios/meeting-notes) |
| [PowerPoint](/products/powerpoint/) | 面向听众的演示与汇报 | [结构、叙事与讲稿](/products/powerpoint/storytelling) | [月度汇报](/scenarios/monthly-report) |

## 配合使用

Excel 保留数据和计算过程，PowerPoint 展示关键发现，Word 记录决策与行动项。复制图表到演示时，先决定是嵌入、链接还是静态图片，并注明数据更新日期。

## 平台与套件

应用名称相同不代表桌面版、网页版和移动版拥有相同功能。版本页提供学习范围和兼容检查方法，不维护完整发布历史。WPS Office 与 LibreOffice 的工作方法和互操作检查见[工具对照](/matrix/)。

[办公练习台](/playground/)只提供结构与计算练习；要完成 `.docx/.pptx/.xlsx`，请在实际办公软件中操作并复核。
