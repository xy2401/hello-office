# 整理、透视与图表

分析前先让数据可读、可筛选、可计算。错误类型或混合口径会让整齐的图表得出错误结论。

## 明细表结构

一行代表一笔费用，一列代表一个字段。表头写“项目、分类、预算（元）、实际（元）”，同列使用一致的数据类型，不在明细中插入小计行或合并单元格。

原始数据保留单独副本，记录来源和截止日期。编号按文本处理，金额按数值处理，缺失值与 0 要区分。

## 清理与检查

1. 核对导入后的行数、字段与数据类型。
2. 筛选空值、重复项和异常金额，先解释原因再更改。
3. 按约定处理多余空格、日期和类别名称。
4. 检查预算与实际是否属于同一时间范围、币种和税费口径。

## 数据透视表

选取完整明细区域或表格，再创建数据透视表。把“分类”放到行，把“预算”和“实际”放到值，并确认汇总方式为求和。金额被识别为文本时，值字段可能变为计数，需要先修正数据类型。

修改源数据后刷新透视表，并检查源范围是否包含新增行。透视结果用于观察，明细仍是核对依据。

## 选择图表

分类比较使用柱形图，时间变化使用折线图。标出单位、期间和来源。预算与实际按相同分类并列，可以直观看到差异；同时在表中保留具体数值。
