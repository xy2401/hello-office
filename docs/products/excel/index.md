# Excel 总览

Excel 用于整理明细、计算指标、筛选信息和分析变化。可靠的工作簿先定义数据口径，再写公式和制作图表。

## 适合的任务与边界

适合费用台账、任务跟踪、预算分析和小规模数据整理。需要多人高并发写入、复杂权限或长期系统集成时，需要另行选择业务系统；工作簿中的公式也不能替代业务口径确认。

原始明细、计算区域和结果展示分开管理。每一行代表一个记录，每一列代表一个字段，不把多个不同含义混在同一列。

## 核心方法

| 要解决的问题 | 对应方法 |
| --- | --- |
| 新增数据容易漏算 | 整理为表格，检查公式范围 |
| 复制公式后结果变化 | 理解相对、绝对和混合引用 |
| 按条件汇总费用 | 使用 SUMIFS 并核对口径 |
| 从编号找对应信息 | 使用可用版本支持的查找函数 |
| 看分类和趋势 | 数据透视表与合适的图表 |

SUMIFS 的参数和适用范围见[微软函数说明](https://support.microsoft.com/en-us/excel/functions/sumifs-function)。
