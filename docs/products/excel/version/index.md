# Excel 版本与平台

本页提供精选兼容说明，不是完整函数或版本清单。记录产品版本、系统和区域设置，再确认函数和数据功能。

## 学习范围

| 环境 | 建议练习 | 需要确认 |
| --- | --- | --- |
| Microsoft 365 桌面版 | 表格、公式、分析与图表 | 更新通道、数据连接与组织策略 |
| Excel 2024/2021 桌面版 | 基础分析及可用的新函数 | 具体函数的适用版本 |
| Excel 2019/2016 | 传统公式与明细分析 | XLOOKUP 不可用，需选择兼容方案 |
| 网页版或移动版 | 基础编辑与协作 | 数据功能、宏及平台差异 |

## 函数兼容

SUMIFS 的语义是多条件求和，适用范围见[微软 SUMIFS](https://support.microsoft.com/en-us/excel/functions/sumifs-function)。XLOOKUP 的版本限制见[微软 XLOOKUP 说明](https://support.microsoft.com/en-us/excel/functions/xlookup-function)，其中注明 Excel 2016 与 2019 不支持该函数。查询日期：2026-10-05。

公式示例采用英文函数名和逗号分隔参数。你的区域设置可能使用其他参数分隔符；按实际软件调整，不能把分隔符错误当成函数不支持。

## 接收方检查

在目标版本中打开工作簿，检查函数名、计算结果、日期、外部链接和图表。重要结果可附值副本与口径说明，但同时保留原始明细及计算过程。CSV 的限制见[文件格式与兼容](/guide/file-formats)。
