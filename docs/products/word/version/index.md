# Word 版本与平台

本页提供精选学习范围，不是完整版本历史。页面方法围绕样式、目录、文档结构和审阅展开；实际入口以你的软件为准。

## 识别当前环境

桌面版先查看“账户”或“关于”中的产品名、版本和构建号，记录 Windows 或 macOS。网页版记录账户与浏览器；移动版适合在自己的设备上另外确认操作入口。

## 学习范围

| 环境 | 建议练习 | 需要确认 |
| --- | --- | --- |
| Microsoft 365 桌面 Word | 完整文档制作与定稿 | 更新通道、版本及组织策略 |
| 永久许可桌面版，如 Word 2024/2021 | 样式、目录与审阅 | 新功能是否适用于该产品版本 |
| Word 网页版 | 日常编辑与协作 | 与桌面版的布局和对象功能差异 |
| 移动版 | 阅读与小范围修改 | 长文档布局和交付操作 |

不要用其他软件或平台的菜单截图作为当前功能已经可用的证据。网页版和桌面版的具体差异以[微软功能对照](https://support.microsoft.com/en-us/word/word-features-comparison-word-for-the-web-vs-desktop)为准，查询日期：2026-10-05。

## 兼容检查

把同一练习文件在接收方软件中打开，检查字体、目录、表格、修订和 PDF 导出。WPS Office 与 LibreOffice 的检查路径见[工具对照](/matrix/)。
