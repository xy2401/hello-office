# Word 总览

Word 用于需要完整阅读、持续修改和正式交付的文字文档，例如会议纪要、工作方案和操作说明。可维护的文档来自结构、样式和审阅流程。

## 适合的任务与边界

适合以文字、标题、表格和插图解释问题。大量计算留在表格中，现场讲解的视觉叙事留在演示中；嵌入的表格或图表需要额外检查更新关系。

长文档先建立标题层级，再应用样式、目录和分页。不要用连续空格对齐，也不要用多个回车模拟分页。

## 核心方法

| 要解决的问题 | 对应方法 |
| --- | --- |
| 所有章节标题保持一致 | 使用并修改标题样式 |
| 快速找到章节 | 用标题结构生成目录 |
| 不同章节使用不同页眉或方向 | 理解分页与分节的区别 |
| 让修改有记录 | 使用批注与修订，逐条确认 |

Word 目录依赖标题结构；桌面与网页版的具体功能有差异，可查[微软功能对照](https://support.microsoft.com/en-us/word/word-features-comparison-word-for-the-web-vs-desktop)。
