# 批注、修订与定稿

批注用于讨论问题，修订用于保留内容变化。审阅的目标是明确哪些修改已经被确认。

## 一次审阅流程

1. 作者提供待审主文件，说明审阅重点和截止时间。
2. 审阅者对需要讨论的位置添加批注，对建议改写的文字开启修订。
3. 作者逐条回复批注，并接受或拒绝每项修订。
4. 定稿前检查未处理项，更新目录，另存最终文件与 PDF。

Word 的桌面版与网页版都提供审阅功能，但具体能力要结合当前平台检查：[微软功能对照](https://support.microsoft.com/en-us/word/word-features-comparison-word-for-the-web-vs-desktop)。

## 不把隐藏当作处理

“无标记”视图只改变显示方式。发送定稿前重新查看所有标记，确认每项修改的处理结果。是否保留批注要由文件用途决定，内部工作记录和外部定稿可以使用不同副本。

## 用批注提出可回答的问题

与其写“这里不清楚”，不如写“本段费用是否包含税费？请说明统计口径”。批注包含具体问题、希望补充的信息和负责确认的人。

## 检查清单

- 名称、日期、数据与来源是否核对。
- 批注是否回复、解决或按约定保留。
- 修订是否逐条确认，而非只隐藏显示。
- PDF 与可编辑源文件是否是同一版本。
