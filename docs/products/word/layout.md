# 样式、目录与分页

目标是制作一份添加内容后仍能保持结构的文档。先处理标题层级，再处理字体、页边距和分页。

## 样式建立结构

1. 把文档分为“背景、结论、证据、行动项”等章节。
2. 一级章节应用“标题 1”，下一级应用“标题 2”，正文应用“正文”样式。
3. 修改样式中的字体、字号和段落间距，让整份文档统一更新。
4. 使用导航窗格检查章节顺序，不要仅用加粗字号假装标题。

初学时最多使用三层标题。标题写内容含义，例如“审批时间缩短两天”，比“情况介绍”更容易帮助读者定位。

## 自动目录

把光标放在目录位置，从“引用”中插入目录。修改章节或分页后更新整个目录，再检查标题层级和页码。功能入口及平台差异见[微软 Word 对照](https://support.microsoft.com/en-us/word/word-features-comparison-word-for-the-web-vs-desktop)。

## 分页与分节

**分页符**用于让下一段从新页开始。**分节符**用于让后续部分采用不同的页眉、页脚、纸张方向或其他节设置。先打开编辑标记，确认文档中有什么断点，再修改布局。

不要用空白段落把内容挤到下一页。横向宽表可以放在独立节，之后检查前后节的页面方向与页眉关系。

## 表格和图片

表格的首行标明字段与单位，长表按实际软件设置检查跨页表头。图片注明图题和来源，检查环绕方式及缩放后的清晰度。

## 交付练习

把[会议纪要素材](/reference/templates)粘贴到 Word，为正文和标题应用样式。加入两段新内容、更新目录、导出 PDF，检查章节与页码是否仍然一致。
