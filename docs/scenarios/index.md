# 场景实战

每个任务都提供输入、制作步骤、交付物和复核点。下载的资料是虚构练习素材，可在你已有的办公软件中完成。

| 任务 | 使用工具 | 输入 | 交付 |
| --- | --- | --- | --- |
| [会议纪要与行动项](/scenarios/meeting-notes) | Word，必要时配合表格 | 会议事实、决定和待办 | 一份纪要与可追踪行动表 |
| [月度工作汇报](/scenarios/monthly-report) | PowerPoint，配合 Word/Excel | 目标、进展、数据和风险 | 五页演示与明细附件 |
| [费用预算与偏差分析](/scenarios/budget-analysis) | Excel | 四笔虚构费用 | 明细、分类汇总与解释 |

## 怎么练习

先读任务页，再在[办公练习台](/playground/)组织结构或修改数字。下载结果后导入实际办公软件，应用样式、公式或版式，最后按清单复核。

任务完成的标准是读者能理解结论、数据可以复核、文件可以交接。网页预览只证明练习素材的结构，不证明原生 Office 文件已完成。
