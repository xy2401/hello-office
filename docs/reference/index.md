# 模板与官方资料

模板用于减少空白页带来的起步成本；官方资料用于确认按钮、平台差异和功能适用范围。

## 本站资源

- [练习素材与模板](/reference/templates)：会议纪要、五页汇报结构和预算 CSV。
- [常用快捷键](/reference/shortcuts)：Windows 桌面常见操作，附官方入口。
- [场景实战](/scenarios/)：把素材做成可交付文件的操作与复核清单。
