# 常用快捷键

以下以 Windows 桌面版的常见操作为例。macOS、网页版、输入法和键盘布局可能不同，快捷键不生效时先检查当前平台与焦点位置。

## 通用编辑

| 操作 | Windows 常见按键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 撤销 | `Ctrl+Z` |
| 复制、粘贴 | `Ctrl+C`、`Ctrl+V` |
| 查找 | `Ctrl+F` |
| 全选 | `Ctrl+A` |

## Excel 常见操作

| 操作 | Windows 桌面常见按键 |
| --- | --- |
| 编辑活动单元格 | `F2` |
| 打开单元格格式 | `Ctrl+1` |
| 开启或关闭筛选 | `Ctrl+Shift+L` |
| 创建表格 | `Ctrl+T` |
| 在编辑引用时切换引用类型 | `F4` |

不要把这些组合键直接视为所有软件的统一行为。Excel 的平台说明和完整列表见[微软快捷键资料](https://support.microsoft.com/en-us/accessibility/excel/keyboard-shortcuts-in-excel)。

## 实际操作原则

先确认当前选中的是正文、形状还是单元格。同一快捷键在不同焦点下可能触发不同操作。浏览器和系统也可能占用按键；经常使用的操作可以同时记住菜单入口。
