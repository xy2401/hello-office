# 从任务到交付

办公软件只是工具。先确定谁要读、需要做什么决定、最终交付什么文件，再选择文档、演示或表格。

## 先选交付物

| 目标 | 首选形式 | 最先做的事 |
| --- | --- | --- |
| 完整说明背景和规则，供反复查阅 | Word 文档 | 列标题层级和读者问题 |
| 在有限时间内讲清楚结论 | PowerPoint 演示 | 写出一句结论和支持证据 |
| 整理数据、计算、筛选和复核 | Excel 工作簿 | 定义每一行、每一列代表什么 |
| 分发一个稳定的阅读版本 | PDF | 先检查源文件，再检查导出结果 |

不要把所有明细塞进演示页，也不要把表格截图当作唯一的数据源。一个任务常需要组合交付物：Excel 保留明细，PowerPoint 讲结果，Word 记录决策。

## 新手学习顺序

1. 阅读[文件格式与兼容](/guide/file-formats)，分清可编辑源文件、阅读版本与纯数据。
2. 做[会议纪要](/scenarios/meeting-notes)，练习标题、列表和行动项。
3. 做[费用预算](/scenarios/budget-analysis)，练习数据类型、引用和汇总。
4. 做[月度汇报](/scenarios/monthly-report)，把数据转成结论与证据。
5. 按[协作交付清单](/guide/collaboration)完成一次交接。

## 每个任务都走四步

**收集**：记录来源、日期和责任人。原始数据单独保留，后续整理在副本中进行。

**组织**：文档先列大纲，演示先列结论，表格先定字段。统一单位、时间范围与命名。

**制作**：应用样式、母版、表格和公式。遇到版本差异，查对应应用的“版本与平台”页和官方资料。

**复核**：读者能否找到重点？数值能否追溯？文件能否打开？审阅和权限是否处理妥当？

## 在哪里练习

[办公练习台](/playground/)用虚构数据练习结构和预算计算。[练习素材](/reference/templates)提供可复制的 Markdown 与 CSV；在自己的软件里另存原生格式，按场景清单检查。教程中的示例是教学材料，不代表真实业务结果。
