# 文件格式与兼容

选择格式时先问：对方要修改内容、阅读定稿，还是继续分析数据？同时记录使用的软件、平台和版本。

## 常见格式

| 格式 | 适合做什么 | 交付时检查 |
| --- | --- | --- |
| `.docx` | 可编辑的文字文档 | 字体、目录、页码、修订与分页 |
| `.pptx` | 可编辑的演示文稿 | 版式、字体、图表、媒体与播放效果 |
| `.xlsx` | 表格、公式和多工作表 | 公式支持、外部链接、日期与计算结果 |
| `.pdf` | 便于阅读与打印的定稿 | 截断、换页、链接、阅读顺序 |
| `.csv` | 交换一张二维表的纯数据 | 编码、分隔符、日期、前导零与数据类型 |
| `.md` | 轻量文字结构和素材 | 在目标软件中重新应用样式和版式 |

CSV 不保存工作表结构、样式或图表；本项目导出的 CSV 是预算练习数据，不是 Excel 工作簿。Markdown 是大纲素材，不是 Word 或 PowerPoint 原生文件。

## 格式相同也要复核

同一个 `.docx/.pptx/.xlsx` 在不同办公套件中打开，字体替换、图表、公式或分页可能出现差异。不要只以“能够打开”作为兼容成功的证据。

建议保留三项：可编辑源文件、供阅读的 PDF、制作环境说明。包含媒体或交互的演示还要在实际播放设备上检查。

## 导入 CSV 的操作

1. 在 Excel 中使用“数据 → 从文本/CSV”，选择 UTF-8 和逗号分隔。
2. 检查预览中的每一列。编号或邮编按文本导入，费用按数值导入，日期按约定格式处理。
3. 检查行数、空值和合计，然后另存 `.xlsx`，再添加公式或图表。

本项目素材使用 UTF-8；练习台下载带 UTF-8 BOM。双击打开仍可能受到本机区域设置影响，推荐明确选择导入参数。

## 定稿检查

- 文件名包含主题、时间范围与状态，例如 `费用分析_2026-09_定稿.xlsx`。
- 日期写完整，金额注明币种和单位，比例说明分母。
- 导出 PDF 后逐页检查标题、表格、图表和页码。
- 对方需要编辑时提供源文件；需要复核数字时提供明细及口径。
