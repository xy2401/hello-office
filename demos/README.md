# 本地办公练习

素材位于 `../docs/public/templates/`，均为虚构数据，不需要下载外部样本。

1. **Word**：打开 `meeting-notes.md`，复制到 Word，设置标题样式，把行动项转成表格，另存 `.docx` 并导出 PDF。检查决定与待确认事项是否分开。
2. **PowerPoint**：打开 `monthly-report.md`，按五页结构创建演示，使用统一版式和备注。另存 `.pptx`，在实际播放环境核对。
3. **Excel**：从文本/CSV 导入 `budget.csv`，选择 UTF-8 与逗号分隔。预算、实际、差额合计应为 3000、3100、100。E2 写 `=D2-C2` 并向下复制，另存 `.xlsx`。

将预算第一笔实际改为 1250 后，总实际应为 3000、总差额为 0。再新增一笔费用，检查汇总范围。

这些说明是本机操作练习，尚未执行跨套件、跨系统或原生 Office 排版验证。完整任务和交付清单见站点的 `scenarios/` 页面。
